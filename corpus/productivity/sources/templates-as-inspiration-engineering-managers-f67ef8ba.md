# Templates as Inspiration for Engineering Managers and Software Engineers

**TL;DR** — The Pragmatic Engineer newsletter's resource page aggregates templates, deepdive reports, and documents that engineering managers and engineers have used successfully across companies.[^src1]

Resource categories:[^src1]

- **Deepdive reports**: MCP usage in the real world, GenZ at the workplace, code freeze approaches, AI coding tools
- **EM templates**: checklists, business case narratives for platform teams, promotion maps, more
- **Hiring**: interview process templates
- **Onboarding**: task lists, email templates, checklists
- **Performance reviews and promotions**: promotion preparation, work log, self-review
- **Engineering career**: bonus chapters from The Software Engineer's Guidebook, goal-writing, "wartime" vs "peacetime" differences
- **For software engineers**: migration checklist, incident analysis template, project reporting template

This is a resource index page, not a single article — useful as a pointer to the Pragmatic Engineer template collection. Full content requires a paid subscription.
