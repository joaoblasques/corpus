# Solomon Hykes

**TL;DR.** Founder and creator of [Docker](/software-engineering/docker.md); currently building Dagger, a CI/CD and software-delivery platform designed around containerized pipelines and now integrating AI agents into DevOps workflows [^src1].

## Background

Grew up in France, studied programming at EpiTech (unconventional French school based on nonstop programming). Pre-Docker built a platform-as-a-service product, which led directly to the containerization insight [^src1].

## Docker (2013)

Docker launched at PyCon 2013 and fundamentally changed how developers ship applications — introducing the container as the standard unit of software delivery. Key innovations [^src1]:
- Pivot from PaaS to open-source engine — gave away the engine, built ecosystem around it
- Developer experience breakthrough: `docker run` as the canonical "works on my machine" fix
- Container images as the portable build artifact, later standardizing on OCI (Open Container Initiative)

Docker made containerization mainstream; its design influenced Kubernetes, CI/CD pipelines, and cloud-native architecture broadly [^src1].

## Dagger

Solomon's next venture. Addresses "the messy, overlooked workflows of software delivery" — the CI/CD and DevOps layer beyond just containerization. Key thesis: "AI agents are reshaping how CI/CD gets done" and the next revolution in DevOps may already be here — coding agents that can manage, generate, and execute delivery workflows autonomously [^src1].
