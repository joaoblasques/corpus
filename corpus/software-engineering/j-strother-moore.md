# J Strother Moore

Computer scientist at SRI International (Menlo Park, California) as of 1979. Co-author with [Robert S. Boyer](/software-engineering/robert-s-boyer.md) of *A Computational Logic* (Academic Press, 1979). [^p01]

Co-developer of the Boyer-Moore string searching algorithm (1977) — the same algorithm whose correctness is mechanically verified in Chapter 18 of the 1979 monograph. This is historically notable: the algorithm's authors used their own theorem prover to verify their concurrent algorithmic work. [^p01]

After SRI, Moore (with Matt Kaufmann) developed **ACL2** (A Computational Logic for Applicative Common Lisp), the industrial-strength successor to the Boyer-Moore prover. ACL2 has been used to formally verify: AMD K5 floating-point division (post-Pentium FDIV), Java bytecode verifier, and various microprocessor designs. [unsourced — general knowledge]

Work at SRI was supported by NSF Grant MCS-7681425 and ONR Contract N00014-75-C-0816. [^p01]

See [Formal Verification and Mechanical Theorem Proving](/software-engineering/formal-verification.md) and [A Computational Logic (source)](/software-engineering/sources/a-computational-logic-1979.md) for the technical content.
