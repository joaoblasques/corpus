# Mathematics for Computer Science (Lehman, Leighton, Meyer — MIT/Google, 2018)

TL;DR: Definitive free CS math textbook (1048pp, CC BY-SA 3.0), coauthored by Eric Lehman (Google), F. Thomson Leighton (MIT/Akamai), Albert R. Meyer (MIT). Used in MIT 6.042J. Covers five major areas: Proofs, Structures, Counting, Probability, and Recurrences. 38 of 41 parts ingested (parts 1–38; parts 39–41 remain). Standard reference for the mathematical foundations of algorithms, data structures, and CS theory.

## Authors and License

- **Eric Lehman** — Google; contributed mathematical practice sections.
- **F. Thomson Leighton** — MIT/Akamai co-founder; contributed combinatorics and algorithms sections.
- **Albert R. Meyer** — MIT CSAIL; primary architect of the logic and proof sections.

Released 2018. License: CC BY-SA 3.0. Used as the official textbook for MIT 6.042J (Mathematics for Computer Science) [^p01].

## Part I: Proofs

### Chapter 1: What is a Proof?

**Proposition**: a statement that is either true or false [^p01].

**Predicate**: a proposition whose truth depends on the value of a variable (e.g., "n² + n + 41 is prime" — true for n = 0…39, false for n = 40) [^p01].

**Axiom**: a proposition assumed to be true without proof. The axiomatic method: build all mathematical knowledge from a small set of axioms via logical inference [^p01].

**Implication (P ⟹ Q)**: "if P then Q"; only false when P is true and Q is false. Implication is vacuously true when P is false (the hypothesis is never triggered) [^p01].

**Proof by cases**: prove the proposition assuming each possible case, then combine [^p01].

**Proof by contradiction**: assume ¬P, derive a contradiction, conclude P. Classic example: √2 is irrational — assume p/q in lowest terms satisfies (p/q)² = 2; derive both p and q must be even, contradicting lowest-terms assumption [^p01].

**Well-ordering principle**: every nonempty subset of ℕ has a least element. Equivalent to induction [^p01].

### Induction (Chapters 2–3)

**Ordinary induction**: (Base case P(0)) ∧ (∀k. P(k) ⟹ P(k+1)) ⟹ ∀n. P(n) [^p02].

**Strong induction**: assume P(0), …, P(k) (all cases up to k) to prove P(k+1). Equivalent in power to ordinary induction [^p02].

**Structural induction**: induction over a recursive structure (e.g., strings, trees). Prove the base cases and the recursive case; structural induction extends ordinary induction to inductively defined sets [^p02].

### Mathematical Data Types (Chapter 4)

Standard sets: ∅ (empty), ℕ (nonneg integers), ℤ (integers), ℚ (rationals), ℝ (reals), ℂ (complex). Superscript '+' restricts to positive elements (ℝ⁺) [^p05].

**Set operations**: S ⊆ T (subset); S ∪ T (union); S ∩ T (intersection); S − T (set difference); |S| (cardinality) [^p05].

**Sequences**: ordered lists; tuples (finite sequences); strings (sequences over an alphabet Σ); Σ* = all finite strings over Σ [^p05].

**Functions**: total (every domain element has an image); partial (may be undefined for some inputs); surjective (onto); injective (one-to-one); bijective (both) [^p05].

**Relations**: binary relations as sets of ordered pairs; relational properties (reflexive, symmetric, antisymmetric, transitive) underpin partial orders and equivalence relations [^p05].

## Part II: Structures

### Chapter 7: Recursive Data Types

**Recursive data types**: defined by a base case and recursive cases. Example: the set of all binary trees; the set of all arithmetic expressions [^p10].

**Nim game (recursive structure)**: positions in Nim form a recursive data type. A position is a losing position (P-position) if and only if every move from it leads to a winning position (N-position); a P-position has no moves or all moves lead to N-positions [^p10].

**Sprague-Grundy theorem**: every finite impartial game is equivalent (in terms of winning strategy) to a Nim heap of some size; the Grundy value (nimber) characterizes this equivalence [^p10].

### Graph Theory (Chapters 8–10)

**Graph** G = (V, E): V = vertices, E = edges (unordered pairs). **Degree** of vertex v: number of edges incident to v. **Handshake lemma**: Σ deg(v) = 2|E| (every edge contributes 2 to the degree sum) [^p08].

**Path**: sequence of distinct vertices v₀, v₁, …, vₖ with each consecutive pair connected by an edge. **Walk**: path allowing repeated vertices. **Cycle**: a closed walk of length ≥ 3 with no repeated vertices except start = end [^p08].

**Connectivity**: G is connected iff there exists a path between every pair of vertices. **Tree**: connected acyclic graph; n vertices ⟹ exactly n−1 edges; uniquely connected [^p08].

**Planar graphs**: can be drawn on the plane without edge crossings. **Euler's formula**: V − E + F = 2 for any connected planar graph (F = faces, including the outer face). Consequence: K₅ and K₃,₃ are non-planar (Kuratowski's theorem) [^p08].

**Graph coloring**: assigning colors to vertices such that no two adjacent vertices share a color. **Chromatic number χ(G)**: minimum colors needed. **Four-color theorem**: every planar graph has χ(G) ≤ 4 [^p08].

**Directed graphs (digraphs)** (Chapter 10): edges are ordered pairs. **DAG** (directed acyclic graph): directed graph with no directed cycles. Topological sort: linear ordering of vertices such that all edges point forward [^p20].

**Partial orders**: a DAG relation that is reflexive, antisymmetric, transitive. **Hasse diagram**: DAG with transitive edges removed and reflexive loops omitted [^p20].

**Walk counting in digraphs**: the (i,j) entry of Aⁿ (n-th power of adjacency matrix A) equals the number of length-n walks from vertex i to vertex j [^p20].

### Number Theory (Chapter 9)

**Divisibility**: a | b iff ∃k ∈ ℤ. b = ka. **GCD** gcd(a,b): largest integer dividing both a and b. **Euclidean algorithm**: gcd(a,b) = gcd(b, a mod b) [^p15].

**Bézout's identity**: ∀a,b ∈ ℤ. ∃s,t ∈ ℤ. sa + tb = gcd(a,b). The extended Euclidean algorithm computes s, t [^p15].

**Prime factorization (Fundamental Theorem of Arithmetic)**: every integer n > 1 factors uniquely into primes [^p15].

**Modular arithmetic**: a ≡ b (mod n) iff n | (a − b). **Multiplicative inverse mod n**: exists iff gcd(a,n) = 1 [^p15].

**RSA cryptosystem** (Chapter 9): based on the difficulty of factoring large composites.
- Choose two large primes p, q; n = pq; φ(n) = (p−1)(q−1).
- Public key: (e, n) where gcd(e, φ(n)) = 1. Private key: d = e⁻¹ mod φ(n).
- Encrypt: c = mᵉ mod n. Decrypt: m = cᵈ mod n.
- Correctness via Euler's theorem: mᵉᵈ ≡ m (mod n) [^p16].

**Water jug example** (GCD application): measuring x liters using jugs of size a and b is possible iff gcd(a,b) | x [^p15].

## Part III: Counting

### Sums and Asymptotics (Chapter 14)

**Closed-form sums**: Σ(i=1 to n) i = n(n+1)/2; Σ(i=0 to n) xⁱ = (xⁿ⁺¹ − 1)/(x − 1) for x ≠ 1 [^p25].

**Integral approximation for sums**: when no closed form is known, replace the sum by an integral ± a boundary term. For weakly increasing f: ∫₁ⁿ f(x) dx ≤ Σ(i=1 to n) f(i) ≤ f(n) + ∫₁ⁿ f(x) dx [^p25].

**Asymptotic notation**:
- f = O(g): f is eventually bounded above by cg for some c > 0
- f = Ω(g): f is eventually bounded below by cg
- f = Θ(g): f = O(g) and f = Ω(g)
- f = o(g): lim f(x)/g(x) = 0 as x → ∞ [^p25]

**Asymptotic equivalences**: ln n = o(nᵉ) for any ε > 0; nᵏ = o(cⁿ) for any k > 0 and c > 1 (polynomials are dominated by exponentials) [^p25].

**Stirling's approximation**: n! ≈ √(2πn) · (n/e)ⁿ; ln(n!) = Θ(n log n) [^p25].

### Counting Rules (Chapter 13)

**Bijection rule**: |A| = |B| iff there exists a bijection A → B. **Sum rule**: |A ∪ B| = |A| + |B| for disjoint sets. **Product rule**: |A × B| = |A| · |B| [^p13].

**Permutations**: ordered arrangements. P(n,k) = n!/(n−k)!. **Combinations**: unordered selections. C(n,k) = n! / (k!(n−k)!) = "n choose k" [^p13].

**Inclusion-exclusion**: |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C| [^p13].

**Stars and bars (multiset counting)**: number of k-element multisets from an n-element set = C(n+k−1, k) [^p13].

**Pigeonhole principle**: if n+1 pigeons occupy n holes, some hole contains ≥ 2 pigeons. Generalized: if kn+1 pigeons occupy n holes, some hole has ≥ k+1 [^p13].

## Part IV: Probability

**Sample space Ω**: countable set of outcomes. **Probability function Pr**: Pr: Ω → [0,1] with Σ Pr(ω) = 1. **Event**: any subset E ⊆ Ω; Pr[E] = Σ_{ω∈E} Pr[ω] [^p17].

**Uniform distribution**: Pr[E] = |E| / |Ω| for finite equally-likely outcomes [^p17].

**Conditional probability**: Pr[A|B] = Pr[A ∩ B] / Pr[B]. **Independence**: A ⊥ B iff Pr[A ∩ B] = Pr[A]Pr[B] [^p17].

**Bayes' theorem**: Pr[A|B] = Pr[B|A] · Pr[A] / Pr[B]. Applied to medical testing: low base rate of a disease dramatically reduces posterior probability even with high-sensitivity tests ("false positive paradox") [^p17].

**Random variables**: function X: Ω → ℝ. **Expectation**: E[X] = Σ_ω X(ω) · Pr[ω] = Σ_x x · Pr[X=x]. **Linearity of expectation**: E[X + Y] = E[X] + E[Y] (holds regardless of independence) [^p18].

**Indicator random variables**: Iₐ = 1 if event A occurs, else 0; E[Iₐ] = Pr[A]. Used to compute expected values via linearity: e.g., expected number of successes in Bernoulli trials [^p18].

**Variance**: Var[X] = E[(X − E[X])²] = E[X²] − (E[X])². **Standard deviation** σ[X] = √Var[X] [^p18].

**Deviation from the Mean (Chapter 20)**:

**Markov's inequality**: for X ≥ 0 and x > 0, Pr[X ≥ x] ≤ E[X] / x. Requires only that X is non-negative; a weak but widely applicable bound [^p38].

**Chebyshev's inequality**: Pr[|X − µ| ≥ x] ≤ σ²/x². Requires only finite variance; sharper than Markov for variables centered near their mean [^p38].

**Chernoff bounds**: exponential tail bounds for sums of independent 0–1 random variables; much tighter than Chebyshev for probabilities of large deviations. Key tool for algorithm analysis (e.g., bounding hashing collision probabilities, load balancing) [^p38].

## Part V: Recurrences (Chapters 16, 21–22)

**Linear recurrence**: a recurrence of the form f(n) = c₁f(n−1) + c₂f(n−2) + … + cₖf(n−k) [^p30].

**Towers of Hanoi**: t₀ = 0, tₙ = 2tₙ₋₁ + 1. Solution via generating functions: T(x) = Σ tₙ xⁿ; manipulate the recurrence to find T(x) in closed form; extract coefficients. Result: tₙ = 2ⁿ − 1 [^p30].

**Fibonacci recurrence**: F₀ = 0, F₁ = 1, Fₙ = Fₙ₋₁ + Fₙ₋₂. Characteristic equation x² = x + 1; roots φ = (1+√5)/2 (golden ratio) and ψ = (1−√5)/2. Closed form (Binet's formula): Fₙ = (φⁿ − ψⁿ)/√5 [^p30].

**Generating function method**: encode a sequence as power series G(x) = Σ aₙ xⁿ; algebraic manipulation on G(x) (e.g., multiplying by x, shifting) mirrors recurrence operations; partial fractions decompose G(x) to extract closed-form coefficients [^p30].

### Chapter 21: Random Walks

**Gambler's Ruin**: gambler starts with n dollars, target T, wins each bet with probability p, loses with q = 1 − p. Let wₙ = probability of reaching T before 0. Recurrence: wₙ = p·wₙ₊₁ + q·wₙ₋₁; boundary conditions w₀ = 0, wT = 1 [^p39].

**Closed-form solution (Gambler's Ruin)**: let r = q/p.
- If p = 1/2 (fair game): wₙ = n/T.
- If p ≠ 1/2 (biased): wₙ = (rⁿ − 1) / (rᵀ − 1).

Derived via generating functions: W(x) = Σ wₙ xⁿ; the denominator rx² − x/p + 1 factors as (1 − x)(1 − rx), enabling partial fractions [^p39].

**Optional stopping theorem (informal)**: in a fair game (r = 1), the generating function derivation confirms wₙ = n/T — the proportion of the target the gambler starts with equals their win probability. More generally, expected worth under a fair betting system stays constant [^p39].

### Chapter 22: Recurrences — Plug-and-Chug, Merge Sort, Akra-Bazzi

**Plug-and-chug method**: alternative to guess-and-verify. Work backward from Tₙ by substituting the recurrence repeatedly (plugging), then simplify without losing the pattern (chugging). Once a pattern is visible, collapse the geometric sum and verify by induction. Example (Towers of Hanoi):
- Tₙ = 2ᵏ · Tₙ₋ₖ + (2ᵏ − 1); choosing k = n − 1 and T₁ = 1 yields Tₙ = 2ⁿ − 1 [^p40].

**Merge Sort recurrence**: T₁ = 0; Tₙ = 2·Tₙ/₂ + n − 1 (n a power of 2). Solution via plug-and-chug: Tₙ = n log₂ n − n + 1 = Θ(n log n). This matches the lower bound for comparison-based sorting [^p40].

**Akra-Bazzi theorem**: general technique for divide-and-conquer recurrences of the form T(n) = Σᵢ aᵢ · T(bᵢn + hᵢ(n)) + g(n). Find p such that Σᵢ aᵢ bᵢᵖ = 1, then T(n) = Θ(nᵖ · (1 + ∫₁ⁿ g(u)/uᵖ⁺¹ du)). Generalizes the Master Theorem to non-uniform splits [^p41].

## Relevance to Software Engineering

This textbook is the standard prerequisite for:
- **Algorithm analysis**: big-O/Ω/Θ notation, recurrence solving, asymptotic reasoning
- **Data structures**: trees, graphs, recursion theory
- **Cryptography**: number theory, modular arithmetic, RSA
- **Probability in systems**: Markov/Chebyshev/Chernoff bounds appear in randomized algorithms, distributed systems analysis (load balancing, hashing), and ML theory
- **Combinatorics in CS**: counting arguments for algorithm correctness proofs
