# The Open Logic Text (Open Logic Project, 2026)

TL;DR: Open-source collaborative textbook of formal metalogic and formal methods (1016pp, CC BY 4.0, revision 9620cc7 dated 2026-07-12). Aimed at philosophy and computer science students at an intermediate level (after introductory formal logic). Covers: sets, relations, functions, cardinality, propositional logic, first-order logic, model theory, computability, incompleteness, and modal/temporal/intuitionistic logics. **All 47 parts ingested** (complete). Parts 17–47 add: Tableaux, Model Theory, Peano Arithmetic, Computability, Incompleteness, Second-Order Logic, Modal Logic, Temporal Logic, Epistemic Logic, Intuitionistic Logic, Conditional Logic, and a mathematical history chapter.

## About the Project

**Open Logic Project** — a collaborative, open-source textbook project. The full source (LaTeX) is freely available and licensed CC BY 4.0, allowing modification and redistribution. The text is "modular": instructors can select which chapters to include. Revision controlled on GitHub [^p01].

## Part I: Sets and Functions (Chapters 1–5)

### Chapter 1: Sets

**Extensionality**: two sets are equal iff they have the same members. This is the foundational axiom of set theory: a set is determined entirely by its elements, not by how it was defined or by its order of listing [^p04].

**Russell's Paradox**: the set R = {x : x ∉ x} leads to contradiction (R ∈ R iff R ∉ R). Shows that unrestricted comprehension ("any property defines a set") is inconsistent. The resolution: Zermelo-Fraenkel (ZF) set theory restricts comprehension to subsets of existing sets [^p04].

**Set operations**: union (∪), intersection (∩), difference (−), power set ℘(A) (set of all subsets), Cartesian product A × B (set of ordered pairs). The power set of A has 2^|A| elements for finite A [^p04].

### Chapter 3: Relations

**Relation**: a subset R ⊆ A × B. A binary relation on A is a subset of A × A. Key properties: reflexive (∀x. xRx), symmetric (xRy → yRx), transitive (xRy ∧ yRz → xRz), antisymmetric (xRy ∧ yRx → x = y) [^p04].

**Equivalence relation**: reflexive + symmetric + transitive. Partitions A into equivalence classes. Canonical example: congruence modulo n [^p05].

**Partial order**: reflexive + antisymmetric + transitive. Examples: ⊆ on sets, ≤ on ℝ. **Linear (total) order**: additionally, every two elements are comparable [^p05].

### Chapter 3–4: Functions and Cardinality

**Injection (one-to-one)**: f: A → B is injective iff f(x) = f(y) → x = y. If f is injective, it has a left inverse g: B → A such that g(f(x)) = x for all x (requires Axiom of Choice for the general case when f is surjective) [^p05].

**Surjection (onto)**: f: A → B is surjective iff every b ∈ B has some a with f(a) = b. A surjective f has a right inverse h: B → A [^p05].

**Bijection**: injective + surjective. A bijection between A and B exists iff |A| = |B| (cardinality equal). Every bijection has a two-sided inverse [^p05].

**Cantor's Theorem**: for any set A, the power set ℘(A) is strictly larger than A — that is, there is no surjection from A onto ℘(A). Proof: for any function g: A → ℘(A), the set D = {x ∈ A : x ∉ g(x)} cannot be in the range of g (the diagonal argument). Therefore |A| < |℘(A)| for all A [^p06].

**Countable vs. uncountable**: a set A is countable (enumerable) iff |A| ≤ |ℕ|. ℕ, ℤ, ℚ are countable; ℝ and ℘(ℕ) are uncountable. A is non-enumerable iff |ℕ| < |A| [^p06].

## Part II: Propositional Logic (Chapters 6–13)

### Chapter 7: Syntax and Semantics of Propositional Logic

**Language L₀**: atomic propositions p₀, p₁, …; connectives ¬, ∧, ∨, →, ⊥. Formulas defined inductively via a formation sequence [^p08].

**Valuation**: a function v: At₀ → {T, F}. Extended inductively to all formulas:
- v(¬φ) = T iff v(φ) = F
- v(φ ∧ ψ) = T iff v(φ) = T and v(ψ) = T
- v(φ → ψ) = T iff v(φ) = F or v(ψ) = T [^p08].

**Satisfaction, validity, entailment**: a formula φ is *valid* (tautology) if v ⊨ φ for every valuation v. Γ *entails* φ (Γ ⊨ φ) if every valuation satisfying all of Γ also satisfies φ [^p08].

### Chapter 9: The Sequent Calculus

**Sequent**: Γ ⇒ Δ where Γ (left side) and Δ (right side) are finite sets of formulas. Semantics: Γ ⇒ Δ is valid iff every valuation satisfying all Γ satisfies some formula in Δ [^p09].

**Structural rules**: weakening (add formulas to either side), contraction (deduplicate), exchange (reorder). **Logical rules**: for each connective, one left rule (eliminating it on the left) and one right rule (introducing it on the right).

**Soundness of the sequent calculus**: every derivable sequent is valid. Proved by induction on the derivation, case-splitting on the last inference rule applied [^p09].

**Completeness**: every valid sequent is derivable. For propositional logic, completeness follows from the existence of saturated sets and the canonical model construction (Lindenbaum–Tarski method) [^p14].

### Chapter 10–11: Axiomatic Derivations and Natural Deduction

**Axiomatic derivation system**: a fixed set of axiom schemas plus modus ponens as the only inference rule. Derivations are sequences of formulas where each is an axiom or follows by modus ponens from prior formulas [^p14].

**Natural deduction**: inference rules that directly correspond to introduction and elimination of connectives. Hypotheses can be introduced and discharged during the proof. More readable than axiomatic systems for informal derivations [^p14].

## Part III: First-Order Logic (Chapters 14–20)

### Chapter 15: Syntax of First-Order Logic

**First-order language L**: constant symbols, function symbols (each with a fixed arity), predicate symbols (each with a fixed arity), equality predicate =, logical symbols ¬, ∧, ∨, →, ∃, ∀ [^p12].

**Terms**: built inductively from variables and constants using function symbols. **Formulas**: built from atomic formulas (predicate applications, identity) using connectives and quantifiers [^p12].

**Syntactic identity (≡)**: used to talk about strings of symbols being literally identical. φ ≡ ψ means φ and ψ are the same formula string character-by-character [^p12].

**Substitution**: t[s/x] denotes the term t with every occurrence of variable x replaced by term s. A variable y is *free* in φ if it is not bound by a quantifier ∀y or ∃y [^p12].

### Chapter 16–20: Semantics and Proof Theory of FOL

**Structure M**: an interpretation of L consisting of a non-empty domain |M|, interpreting each constant as an element, each function symbol as a function, each predicate symbol as a relation. **Variable assignment s**: a function assigning each variable to an element of |M| [^p16].

**Satisfaction (M ⊨ φ[s])**: defined inductively. For ∃x φ: M ⊨ (∃x φ)[s] iff there exists d ∈ |M| such that M ⊨ φ[s[x/d]] [^p16].

**Soundness of FOL proof systems**: if Γ ⊢ φ (φ is derivable from Γ), then Γ ⊨ φ (φ is entailed by Γ). Proved by induction on derivations, including the natural deduction rules for quantifiers [^p16].

**Completeness of FOL (Gödel, 1929)**: if Γ ⊨ φ then Γ ⊢ φ. This is harder — requires constructing a canonical model from a maximally consistent set of formulas. Proved via the Lindenbaum–Tarski method [^p14].

**Soundness vs. Completeness distinction**: soundness says the proof system does not prove falsehoods; completeness says it proves everything true. Both are required for a useful proof system. Gödel's completeness theorem (1929) confirmed FOL has both; his incompleteness theorems (1931) showed that sufficiently strong arithmetic systems cannot have both for arithmetic truth [^p14].

## Part IV: Tableaux and Proof Theory (Chapters 21–27) [^p17]

### Chapter 21–22: Tableaux for FOL

**Signed tableau method**: formulas prefixed with T (true) or F (false). A branch closes when it contains both T φ and F φ for the same formula. A tableau is closed when all branches close. The method is refutation-based: to prove φ, construct a tableau for F φ; a closed tableau shows φ is valid [^p17].

**Soundness of tableaux with identity**: if a branch is satisfiable and a rule is applied (including the identity rules =T and =F), the resulting branch is also satisfiable. Identity rule =T: from T(t₁ = t₂) and T φ(t₁), conclude T φ(t₂), replacing occurrences of t₁ in φ with t₂ [^p17].

**Completeness of tableaux**: every valid FOL formula has a closed tableau. Proved by constructing a canonical countermodel from any open, saturated branch [^p17].

### Chapters 23–27: Sequent Calculus for FOL and Proof Arithmetic

**LK (Gentzen's sequent calculus)**: uses sequents Γ ⇒ Δ. Structural rules (weakening WL/WR, contraction CL/CR, exchange XL/XR) plus logical rules for each connective. Cut elimination (Gentzen's Hauptsatz) is the central metatheorem: any proof using the Cut rule can be transformed into a cut-free proof [^p27].

**Gödel numbering of proofs**: proofs in LK can be coded as natural numbers. With one-premise inference rules, the code is ⟨1, code(subproof), code(conclusion), k⟩ where k identifies the rule; two-premise rules use ⟨2, code(π₁), code(π₂), code(conclusion), k⟩. This encoding is primitive recursive [^p27].

## Part V: Model Theory (Chapters 25–27) [^p20]

### Isomorphism and Elementary Equivalence

**Isomorphism**: a bijection h: |M| → |N| preserving all relations and functions. Isomorphic structures satisfy exactly the same sentences. **Elementary equivalence** (M ≡ N): same theory (all sentences satisfied), but not necessarily isomorphic [^p20].

**Standard models of Peano Arithmetic**: the unique (up to isomorphism) standard model N = ⟨ℕ, 0, ′, +, ×, <⟩. Every element of the domain equals Val_M(n) for some numeral n. A structure isomorphic to N is standard [^p20].

**Non-standard models**: structures satisfying all first-order sentences true in N but not isomorphic to N. They contain "non-standard numbers" — elements not equal to Val_M(n) for any n. The existence of non-standard models follows from the compactness theorem [^p20].

**Löwenheim-Skolem theorems**: 
- *Downward*: If a theory T has an infinite model, it has a countable model.
- *Upward*: If T has an infinite model, it has models of every infinite cardinality.
Together these show first-order logic cannot characterize structures up to isomorphism for infinite domains (incompleteness of FOL for categoricity) [^p20].

## Part VI: Computability (Chapters 28–35) [^p22] [^p25]

### Primitive Recursive and Recursive Functions [^p22]

**Primitive recursive functions**: built from zero, successor, and projection by composition and primitive recursion. All basic arithmetic operations (addition, multiplication, exponentiation, factorial, gcd, Fibonacci numbers) are primitive recursive.

**Coding sequences**: natural numbers can encode finite sequences via a primitive recursive bijection (using the Chinese Remainder Theorem or prime factorization). This enables the coding of syntactic objects (formulas, proofs, computations) as numbers — the basis of Gödel numbering [^p22].

**Trees and their codes**: a tree can be coded as a sequence ⟨k, d₁, …, dₖ⟩ where k is the number of immediate subtrees and d₁, …, dₖ their codes. The function SubtreeSeq(t) returning all subtrees is primitive recursive [^p22].

**Recursive (total computable) functions**: primitive recursive functions plus minimization (μ-operator). The minimization of a primitive recursive function f is μy f(x, y) = 0 — the least y making f(x, y) = 0. Partial recursive functions extend this to possibly undefined values [^p22].

### Turing Machines [^p25]

**Turing machine**: a finite state machine with a one-way infinite tape, a head that reads and writes, and a set of transitions (state, read-symbol) → (write-symbol, move, new-state). Halting is signaled by reaching a designated halting state.

**Church-Turing thesis**: every intuitively computable function is Turing-computable (equivalently: computable by partial recursive functions, register machines, or any other reasonable model). This is a thesis, not a theorem, but is universally accepted [^p25].

**Universal Turing machine U**: given the Gödel number e of machine Mₑ and input n, U simulates Mₑ on n. U first decodes e from the tape, then emulates Mₑ's tape transitions using its own tape as a representation of Mₑ's state. This shows the existence of a single universal program [^p25].

**Halting problem**: the function Halt(e, n) = 1 if Mₑ halts on n, else 0, is not computable. Proof by diagonalization: if Halt were computable, construct a machine D that halts iff D does not halt on its own index — contradiction. Hence undecidability is a fundamental feature of computation, not an accident of particular proof systems [^p25].

### Undecidability and Reducibility [^p25]

**Many-one reduction**: A ≤ₘ B (A reduces to B) if there exists a computable f such that n ∈ A iff f(n) ∈ B. If B is decidable and A ≤ₘ B, then A is decidable. The halting set K is m-complete among recursively enumerable sets.

**Rice's theorem**: for any non-trivial property P of partial recursive functions, the set {e : φₑ has property P} is undecidable. "Non-trivial" means P holds for some functions but not all. Rice's theorem implies: you cannot decide in general whether a program halts, outputs a specific value, is equivalent to another program, etc. [^p25].

## Part VII: Incompleteness (Chapters 36–37) [^p27]

### Peano Arithmetic and Representability

**Peano Arithmetic (PA)**: axioms for successor (0 ≠ n′, injectivity of ′), recursion equations for + and ×, and the induction schema (for each formula φ). PA is a first-order theory strong enough to interpret basic arithmetic.

**Representability**: a function f is representable in PA if there exists a formula R_f(x̄, y) such that PA ⊢ R_f(n̄, m̄) iff f(n̄) = m. All primitive recursive functions are representable. This allows encoding of syntax and proofs as numbers that PA can reason about.

**Gödel's First Incompleteness Theorem (1931)**: any consistent, recursively axiomatized extension of PA is incomplete — there exists a sentence G (the Gödel sentence, "This sentence is not provable") such that neither G nor ¬G is provable. G is true (in the standard model) but not provable [^p27].

**Gödel's Second Incompleteness Theorem**: PA cannot prove its own consistency (Con(PA)) unless it is inconsistent. Formalized as: PA ⊢ Con(PA) → G, hence if PA ⊢ Con(PA) then PA ⊢ G, contradicting incompleteness. Consistency of a theory strong enough to express arithmetic cannot be proved within that theory [^p27].

**ω-completeness and ω-consistency**: a theory is ω-consistent if it never proves ∃x ¬φ(x) while also proving φ(n) for every numeral n. Gödel's original proof used ω-consistency; Rosser (1936) strengthened it to require only ordinary consistency [^p27].

## Part VIII: Second-Order Logic (Chapters 38–40) [^p30]

**Second-order logic (SOL)**: extends FOL by allowing quantification over relations and functions (not just individuals). Second-order variables X (relation), u (function) range over subsets of (or functions on) the domain.

**Satisfaction for SOL**: the assignment s now assigns second-order variables to relations/functions over |M|. s[M/X] replaces X with a relation M ⊆ |M|ⁿ. Existential quantification over relations: M, s ⊨ ∃X φ iff there exists some relation R over |M| such that M, s[R/X] ⊨ φ [^p30].

**Categoricity**: SOL achieves what FOL cannot. Second-order Peano Arithmetic is *categorical* — all its models are isomorphic to the standard model ℕ. This is because the second-order induction axiom ∀X[(X0 ∧ ∀y(Xy → Xy′)) → ∀yXy] forces the domain to be exactly ℕ [^p30].

**Limitations**: SOL is not complete — there is no sound and complete proof system for full SOL (Gödel's completeness theorem fails for SOL). The set of SOL validities is not recursively enumerable. SOL is more expressive than FOL but loses the key metalogical properties (completeness, compactness, Löwenheim-Skolem) [^p30].

## Part IX: Modal Logic (Chapters 41–52) [^p35]

### Syntax and Semantics

**Modal operators**: □ (necessity/box) and ◇ (possibility/diamond), defined as ◇φ ≡ ¬□¬φ. The language is the classical propositional language extended with these operators [^p35].

**Kripke semantics (relational structures)**: a modal model M = ⟨W, R, V⟩ where W is a set of worlds, R ⊆ W × W is the accessibility relation, V: At → ℘(W) assigns proposition letters to sets of worlds. M, w ⊨ □φ iff for all v with Rwv, M, v ⊨ φ [^p35].

**Normal modal logics**: a modal logic L is normal if it contains all tautologies, the axiom K (□(φ→ψ) → (□φ → □ψ)), and is closed under modus ponens, uniform substitution, and necessitation (from ⊢φ infer ⊢□φ). The minimal normal modal logic K is axiomatized by K alone [^p35].

**Frame conditions and corresponding axioms**:
- T (reflexivity: Rww for all w): □φ → φ (what is necessary is true)
- 4 (transitivity): □φ → □□φ  
- B (symmetry: Ruv → Rvu): φ → □◇φ
- D (seriality: ∀w∃v Rwv): □φ → ◇φ
- 5 (Euclidean: Ruv ∧ Ruw → Rvw): ◇φ → □◇φ

Common logics: **KT** (reflexive), **K4** (transitive), **S4** = KT + 4 (reflexive + transitive), **S5** = S4 + 5 (equivalence relation) [^p35].

**Hilbert-type derivation systems for modal logic**: for normal modal logics, two inference rules suffice (modus ponens + necessitation) plus tautology instances, K axiom instances, and appropriate frame axioms. Soundness: proved by induction on derivations. Completeness: canonical model construction where worlds are maximal consistent sets of formulas [^p35].

## Part X: Temporal, Epistemic, and Intuitionistic Logic (Chapters 53–57) [^p40]

### Temporal Logic

**Linear temporal logic (LTL)**: time modeled as a linear order (ℤ or ℕ). Operators: G (globally/always), F (finally/eventually), X (next), U (until). M, t ⊨ Gφ iff M, t′ ⊨ φ for all t′ ≥ t. LTL is widely used in software model checking (TLA+, Spin) [^p40].

**Branching time (CTL)**: time as a tree of possible futures. Operators combine path quantifiers (A = "all paths", E = "some path") with temporal operators (X, G, F, U). CTL* unifies LTL and CTL. CTL model checking is PTIME-complete; LTL is PSPACE-complete [^p40].

**Conditional logic**: Lewis-Stalnaker "sphere semantics" for counterfactuals. M = ⟨W, O, V⟩ where O_w is a nested system of spheres (sets of worlds) centered on w, representing relative closeness. φ □→ ψ is true at w iff the innermost sphere admitting a φ-world satisfies ψ throughout. Transitivity of the conditional fails: (p □→ q) ∧ (q □→ r) ⊭ (p □→ r) [^p40].

### Epistemic Logic

**Epistemic logic**: modal logic where □_a is "agent a knows." Kripke models represent epistemic states: Rwv means world v is epistemically accessible to the agent from w (the agent cannot distinguish w from v). S5 (accessibility = equivalence relation) is the standard for perfect knowledge; weaker logics model fallible agents [^p40].

### Intuitionistic Logic

**Intuitionistic logic**: constructive alternative to classical logic. Truth is equated with the existence of a proof; excluded middle (φ ∨ ¬φ) is not universally valid. A proof of ¬φ means there is no proof of φ (i.e., ¬φ = φ → ⊥).

**Kripke semantics for intuitionistic logic**: models M = ⟨W, ≤, V⟩ where ≤ is a partial order (representing stages of knowledge), and V is monotone (if w ⊨ p and w ≤ v then v ⊨ p). Disjunction: w ⊨ φ ∨ ψ iff w ⊨ φ or w ⊨ ψ. Negation: w ⊨ ¬φ iff for all v ≥ w, v ⊭ φ [^p45].

**Curry-Howard correspondence**: intuitionistic logic is equivalent to the typed lambda calculus (simple type theory). Propositions correspond to types; proofs correspond to terms; proof normalization corresponds to program evaluation. This is the mathematical foundation for dependent type theory and proof assistants (Coq, Agda, Lean) [^p45].

## Part XI: History and Philosophy of Mathematics (Chapter 76) [^p47]

**Background to set theory**: the late 19th century saw "pathological" functions — Weierstrass's continuous-but-nowhere-differentiable function, Peano's space-filling curve, Hilbert's curve — that contradicted geometric intuition. These were used as propaganda for rigorous, set-theoretic foundations [^p47].

**Cantor's continuum hypothesis**: Cantor conjectured that there is no set S with |ℕ| < |S| < |ℝ| (i.e., the continuum is the "next" infinity after ℵ₀). Hilbert listed it as Problem 1. Gödel (1940) showed CH is consistent with ZFC; Cohen (1963) showed ¬CH is also consistent — CH is independent of ZFC [^p47].

## Relevance to Software Engineering

- **Formal verification**: FOL and proof systems are the mathematical basis for formal specification languages (TLA+, Alloy, Z notation) and theorem provers (Coq, Isabelle, Lean).
- **Type theory**: the Curry-Howard correspondence maps logical proofs to programs; propositional logic corresponds to simply-typed lambda calculus; intuitionistic logic is the logic of constructive proof assistants.
- **Database theory**: relational databases are implementations of first-order theories; SQL queries correspond to FOL formulas.
- **Model checking**: temporal logic (CTL, LTL) is used in software model checking tools to specify and verify concurrent system properties.
- **Computability and limits**: understanding Gödel's incompleteness and the halting problem sets principled bounds on what can be automated or formally verified.
- **Epistemics**: epistemic logic formalizes agent knowledge; applied in distributed systems consensus proofs and security protocol verification.
