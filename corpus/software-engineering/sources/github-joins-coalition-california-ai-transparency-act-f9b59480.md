# GitHub Joins Coalition Advocating for Fixes to California AI Transparency Act

**TL;DR** — GitHub, Black Forest Labs, Hugging Face, and Mozilla formed a coalition calling for targeted amendments to California's AI Transparency Act (SB 942/SB 1000), arguing that license revocation provisions conflict with how open source licenses work in practice.[^src1]

The bill as drafted requires developers to revoke licenses if downstream users fail to meet obligations. Open source licenses are designed to be "perpetual and irrevocable" — this is what allows reliable building, reuse, and sharing across projects and organizations. The proposed language "could introduce uncertainty across the software supply chain — particularly for collaborative and community-driven projects."[^src1]

Coalition position: the revocation requirement is not necessary to achieve the bill's transparency goals, because "developers who modify and deploy AI systems are already directly covered by the law." The proposed alternative: align with the EU AI Act Transparency Code of Practice, which "recognizes the distinct nature of the open source ecosystem and acknowledges that notifying downstream users of best practices in documentation is sufficient."[^src1]
