# Why AI-Generated Code Hurts Your Exit — Arvid Kahl

Source: thebootstrappedfounder.com. Ingested to [/ai-business/bootstrapped-saas-playbook.md].

Comprehension debt: distinct from technical debt. Technical debt = consciously deferred work you know about. Comprehension debt = you don't comprehend what the system does because you never built the understanding. Peter Naur's "theory building": code implodes when the team that has the theory of that code is dissolved. AI makes this exponentially worse — the model builds an internal mental model to implement a feature, then that model is immediately lost after the prompt completes. Business transfer problem: acquirers can't value what they can't grasp; private equity will price in comprehension debt. Fighting it: require comments in system prompts, document choices, log prompts used. "Your business isn't just the code. It's the understanding of what that code does."[^1]
