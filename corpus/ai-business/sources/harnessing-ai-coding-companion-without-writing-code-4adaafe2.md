# Harnessing AI as Your Coding Companion Without Writing Code — Arvid Kahl

Source: thebootstrappedfounder.com. Ingested to [/ai-business/bootstrapped-saas-playbook.md].

AI as a pair programmer who never touches the keyboard — investigator, not code writer. Key: tell AI in the system prompt "do not write code, only guide me." Warning about sycophantic exuberance: AI will say your code is perfect unless you explicitly ask for "detached professional critique." Cross-language optimization: AI is great at SQL query optimization given EXPLAIN ANALYZE output + table schema. Security review: create a security preferences prompt, have Claude scan code and recent commits. Code review for solopreneurs: AI can catch code that doesn't do what it appears to do, wrong library versions, missing tests, circular dependencies. Documentation for exit value: AI can identify what test coverage and documentation would make the business more sellable.[^1]
