# How to Create Free, On-Brand LinkedIn Carousels

**TL;DR** — Builder.io's Agent Native Slides template is a cloneable, agent-native tool that generates LinkedIn-spec carousels (1:1 or 4:5, billboard typography) wired to your design system. Concrete example of the cloneable-SaaS pattern.[^src1]

LinkedIn carousels (PDF "documents") require 1:1 or 4:5 aspect ratio and billboard typography. Standard tools (Canva, generic AI deck tools) don't handle brand context or aspect ratio correctly.[^src1]

The Agent Native Slides template: open at slides.agent-native.com, connect Builder.io for free Claude (Opus/Sonnet) credits, provide a design system reference (Figma URL, brand PDF, GitHub repo, screenshots), set LinkedIn constraints in plain English, then provide source material. Agent generates carousel; iterate conversationally.[^src1]

Key pattern: "instead of bending a generic SaaS app to your brand, you clone a small, focused template and wire it into your own context." The agent and canvas are one system reading and writing the same deck against real brand context.[^src1]
