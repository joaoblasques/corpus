# "AI Production Issue Detection: A Failure Taxonomy and Detection Framework - Confident AI"

> **Quick intake** (obsidian-list). [open source](https://www.confident-ai.com/knowledge-base/guides/ai-production-issue-detection-framework)

The document discusses AI production issue detection, a practice that catches semantic failures in deployed LLM applications that traditional monitoring cannot see. It proposes a five-layer detection framework: instrumentation, signal classification, online evaluation, drift detection, and alerting with human review. The framework aims to detect six recurring failure modes: tool misuse, context loss, goal drift, silent quality degradation, retrieval failure, and policy violations.
